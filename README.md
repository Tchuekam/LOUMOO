# LOUMOO — Universal Commerce Platform

A next-generation universal digital commerce ecosystem and interactive prototype built with high-fidelity UI/UX design patterns, dual mobile/desktop responsive views, and dark mode support.

## Overview
- **Universal Commerce**: Unified digital ecosystem for products, services, travel bookings, announcements, and job/tender postings.
- **Responsive Design**: Dedicated desktop application layout (`≥ 1024px`) with a sidebar navigation and topbar, and mobile device layout (`< 1024px`).
- **Modernist Design System**: Flat, architectural UI design system with 0px radius, curated typography (Archivo), high-contrast palettes, and full Dark Mode support.
- **Multi-Destination Navigation**: Home, Store Directory, VS Compare Matrix, Travel Booking, Announcements, Chat / Messaging, Cart, Saved Items, Profile, and Seller Studio.

## Getting Started
To view the prototype locally:
```bash
python -m http.server 8080
```
Then open:
`http://localhost:8080/Commerce App.dc.html`
